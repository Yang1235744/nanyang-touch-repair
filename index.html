核心功能

🛠 一键修复触摸

注册表修复 + 低级鼠标钩子，解决单点无效、需滑动触发、点击多次才响应等 Win10/11 触摸故障

🎯 触摸校准

调用系统 TabletPC 校准面板，重新校正触摸坐标偏移

📱 安卓环境沙盒

自动检测雷电模拟器，静默运行安卓应用，安装 APK 并创建桌面快捷方式

↩ 触摸恢复

撤销所有修复项，恢复系统默认触摸行为

🎨 UI 自定义

主题色自定义、必应每日壁纸（普通版）/ Furry 壁纸（特别版）

🔄 自动更新

普通版支持 GitHub 在线更新，多镜像源回退保障网络稳定

版本选择

🟦 普通版 持续更新

必应每日风景壁纸，功能持续迭代更新。适合需要最新功能的用户。

🟧 Furry 特别版 功能锁定

壁纸替换为 Furry 主题（来源 e621，safe 级别），功能已锁定不再推送更新。仅壁纸主题不同。

系统要求

• Windows 10 / Windows 11（64 位）

• .NET 10 运行时（单文件版已内嵌，无需单独安装）

• 触摸修复功能需要管理员权限

• 安卓环境需要 CPU 支持虚拟化且 BIOS 已开启 VT-x
